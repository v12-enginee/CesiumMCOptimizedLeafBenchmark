# CesiumOptimizedLeaf

Optimized Leaf for CesiumMC (CesiumOptimizedLeaf). Currently 1.21.4 only.

## Tested hardware:

**Ryzen 9 7900**  
**64 GB of DDR5**  
**2 TB Samsung NVMe**

## Stress test results:

Lobby held **300 players at 20 TPS**, with **4 GB of RAM allocated**. Peak RAM usage was **3 GB**. Struggled to keep up past **400 players**.

Survival holds **60 players** scattered around the map at **20 TPS**, with **16 GB of RAM allocated**. Average RAM usage was **6 GB**.

With the RTP radius pregenerated, a **10-chunk render distance** fully loads in under **1.5 seconds**.
